# RouteGate Trademark Research Notes

This document records practical trademark research notes for the RouteGate project. It is not legal advice and does not replace review by a qualified trademark attorney or patent/trademark representative.

RouteGate is an open-source self-hosted Linux VPN Management Platform. The software is licensed separately from the RouteGate name, marks, logos, icons, and other brand assets. See `../TRADEMARKS.md` for the project trademark and official/unofficial builds boundary.

## Research Goals

Before filing any trademark application, research should verify:

- whether identical or confusingly similar marks already exist;
- whether `ROUTEGATE` is distinctive enough for software and related services;
- which Nice Classification classes match the project scope;
- whether any target country or region has elevated conflict risk;
- whether Madrid System filing, direct national filings, or a combined route is more appropriate;
- whether official builds, signed releases, support, appliance packaging, and managed operation can be described without creating artificial software editions.

No trademark applications, payments, assignments, or representative engagements should be made from this repository workflow.

## Preliminary Nice Classification Scope

The initial research focus should be on classes that match the current and foreseeable RouteGate project boundary.

### Class 9 — Downloadable Software

Class 9 is expected to be the primary software class for downloadable RouteGate components, including Manager, Agent, installers, release artifacts, client configuration tooling, and related server-side software.

Possible goods wording to validate with a trademark professional:

> Downloadable computer software for deploying, configuring, managing, monitoring, and maintaining self-hosted virtual private network infrastructure; downloadable server software for virtual private network management; downloadable computer software for managing VPN servers, VPN user accounts, routing profiles, network access policies, client configuration profiles, traffic usage, and configuration deployment; downloadable computer software for Linux server infrastructure management; downloadable computer software for secure remote network access management.

### Class 42 — Software and Technical Services

Class 42 is expected to cover software development, maintenance, technical support, hosted management, SaaS/PaaS, consulting, deployment assistance, updates, and managed RouteGate-related software services.

Possible services wording to validate with a trademark professional:

> Software as a service (SaaS) featuring software for deploying, configuring, managing, monitoring, and maintaining self-hosted virtual private network infrastructure; platform as a service (PaaS) featuring software platforms for VPN infrastructure management; design, development, installation, maintenance, updating, and support of computer software for VPN infrastructure management; technical consultancy in the field of self-hosted VPN infrastructure, network security software, and Linux server infrastructure; computer security services, namely, providing technical configuration, monitoring, and software maintenance services for secure network access systems.

### Class 38 — Telecommunications Services

Class 38 should be treated as optional and strategic. It may become relevant only if RouteGate is used as the brand for telecommunications or VPN access services, rather than only as self-hosted software and related technical services.

Possible services wording to validate if this class is needed:

> Providing secure telecommunications connections to private and public computer networks; providing virtual private network (VPN) telecommunications services; transmission of encrypted data via computer networks; providing secure remote access to computer networks.

## Risk Review Principles

- Do not treat absence of an exact match as clearance.
- Review confusing similarity, not only identical marks.
- Distinguish active filings and registrations from cancelled, expired, withdrawn, or refused records.
- Do not treat unrelated industry use as an automatic blocker.
- Pay special attention to classes 9, 38, and 42.
- Treat class 38 as higher sensitivity because it is closer to telecommunications and VPN service branding.
- In the United States, check both registered marks and actual commercial use.
- Keep factual search results separate from legal conclusions.

## Ownership and Future Transfer Notes

Initial ownership, assignment, licensing, and future transfer strategy should be reviewed outside this repository with qualified professionals before any filing. The repository should not contain private personal, tax, residency, payment, or corporate-structuring details.

A later business entity may receive the mark by assignment or license only after the legal, tax, and operational structure is real and properly documented.
