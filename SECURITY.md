# Security Policy

RouteGate manages routing and VPN-adjacent infrastructure, so security reports
are handled carefully even during early project stages.

## Supported Versions

Until the project publishes a stable release policy, security fixes target the
default branch and the most recent public release, when applicable.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately.

Preferred reporting path:

1. Use GitHub private vulnerability reporting for this repository when it is
   available.
2. If private vulnerability reporting is unavailable, contact a maintainer
   privately before opening a public issue.

Please include:

- Affected component or endpoint.
- Steps to reproduce.
- Expected and observed behavior.
- Impact, including the data or permissions involved.
- Any suggested mitigation, if known.

Do not include active exploit payloads, credentials, tokens, private keys,
production data, or unnecessary personal data.

## Disclosure

Maintainers will make a good-faith effort to acknowledge reports promptly,
investigate the issue, prepare a fix when appropriate, and coordinate public
disclosure after users have a reasonable opportunity to update.

Please do not publicly disclose a vulnerability before maintainers have had a
reasonable opportunity to respond and remediate.
