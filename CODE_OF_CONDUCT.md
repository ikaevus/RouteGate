# Code of Conduct

RouteGate is committed to a respectful, harassment-free project environment.
Everyone participating in the project is expected to help make collaboration
welcoming, direct, and productive.

## Expected Behavior

- Be respectful of differing experience levels, backgrounds, and viewpoints.
- Give and receive technical feedback in good faith.
- Keep discussions focused on the work and its impact.
- Acknowledge mistakes and correct them when possible.
- Respect maintainer decisions about scope, timing, and project direction.

## Unacceptable Behavior

- Harassment, threats, intimidation, or sustained disruption.
- Discriminatory language or conduct.
- Personal attacks, insults, or demeaning comments.
- Publishing private communications or personal information without consent.
- Sexualized language, imagery, or attention in project spaces.
- Any conduct that maintainers reasonably determine to be inappropriate for a
  professional open source project.

## Scope

This code applies in repository discussions, issues, pull requests, project
chat, events, and any other spaces where someone represents the RouteGate
project.

## Enforcement

Maintainers may remove comments, close issues or pull requests, moderate access,
or take other reasonable action to protect the project community.

If you experience or observe unacceptable behavior, contact a project maintainer
privately when possible. Reports will be reviewed with care and handled with as
much confidentiality as practical.
